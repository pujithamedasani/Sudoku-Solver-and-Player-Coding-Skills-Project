# Sudoku Solver and Player (C++)

A console-based Sudoku player and solver implemented in C++. This project demonstrates algorithmic problem-solving using Backtracking, Greedy heuristics, and Dynamic Programming (DP) concepts.


---

🚀 Features

Play Sudoku interactively in the console

Input custom puzzles

Real-time move validation

Automatic puzzle solving

Efficient algorithm using heuristics

Clean and modular C++ code



---

🧠 Algorithms Used

Backtracking – Ensures correct solution by exploring all possibilities

Greedy Approach – Selects the most constrained cell to optimize solving

Dynamic Programming (DP) – Caches intermediate results to avoid recomputation



---

🛠️ Technologies

Language: C++

Concepts: Recursion, Matrix Handling, Optimization Techniques



---

▶️ How to Run

1. Compile the code:

g++ sudoku.cpp -o sudoku


2. Run the program:

./sudoku




---

📌 Usage

Enter the Sudoku grid (use 0 for empty cells)

Choose to either solve automatically or play manually

Follow on-screen instructions



---

📂 Project Structure

sudoku.cpp    # Main source code
sudoku.exe    # Executable (optional)

🎯 Purpose

This project is designed for learning and demonstrating algorithm design in C++. It can be extended with GUI, difficulty levels, or advanced solving techniques.
